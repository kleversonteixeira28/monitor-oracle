Baixar o Ubuntu para o servidor de monitoramento

Links conferidos em 10/09/2026 direto do releases.ubuntu.com.

Baixe este

Ubuntu Server 26.04.1 LTS  ·  2,7 GB
ubuntu-26.04.1-live-server-amd64.iso
Para qualquer PC ou mini PC comum (Intel/AMD). Suporte de segurança até 2036. Confirmei que o Docker publica repositório para esta versão — era o risco de pegar uma versão nova demais.
Server, não Desktop. A versão Desktop tem 6 GB e carrega interface gráfica que só consome memória numa máquina que vai ficar num canto. Nada do que a gente instalou precisa de tela.

Se der problema de hardware

Ubuntu Server 24.04.4 LTS  ·  3,2 GB
ubuntu-24.04.4-live-server-amd64.iso
A LTS anterior, mais rodada. Use se a 26.04 travar no boot ou não reconhecer a rede da máquina — coisa que acontece mais com hardware muito antigo do que com hardware novo.

Conferir o download (opcional, 30 segundos)

No PowerShell, na pasta onde baixou:

certutil -hashfile ubuntu-26.04.1-live-server-amd64.iso SHA256

Tem que bater com:

cc8a95cde20f6ced61a322420de00f10cc3c90ced545daa46cb9c1a117f1d927

Se não bater, o download veio corrompido — baixe de novo. Vale a pena: ISO quebrada dá erro no meio da instalação, e aí você não sabe se o problema é o pen drive, a máquina ou o arquivo.

Gravar o pen drive

Rufus (Windows, gratuito, não precisa instalar). Escolha o pen drive, escolha a ISO, deixe todo o resto no padrão e mande gravar. O pen drive é apagado — use um vazio, de 4 GB ou mais.

Na hora de instalar — o que marcar

  • Install OpenSSH server — esta é a que importa. Sem ela você não entra na máquina pela rede e vai ter que ligar teclado e monitor toda vez.
  • Idioma e teclado: Português (Brasil).
  • Tipo de instalação: Ubuntu Server, não a "minimized". A minimizada tira ferramentas que os scripts usam.
  • Disco: usar o disco inteiro, com o padrão que ele sugerir.
  • Não marque nenhum snap na tela de "Featured server snaps". Docker por snap conflita com o que a gente instala.
  • Guarde o usuário e a senha que você criar — é com eles que você entra.

Depois que instalar

Ligue a máquina na rede por cabo, descubra o IP dela com ip a, e do seu PC entre com ssh usuario@IP. Daí:

sudo apt update && sudo apt install -y git

sudo git clone https://github.com/kleversonteixeira28/monitor-oracle.git /opt/monitor

sudo bash /opt/monitor/local/instalar-servidor-local.sh

Ele pergunta o domínio, prepara a máquina inteira e instala o túnel da Cloudflare no fim.

Se a máquina for um Raspberry Pi, o arquivo é outro (imagem ARM, não esta ISO) — me avise antes de baixar.
